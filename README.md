# 朋友圈详情模拟 H5

原生 HTML / CSS / JavaScript 实现，无前端依赖。配置头像、昵称、文案、配图、发送时间和点赞用户，点击“发表”保存本次配置并进入独立的 `detail.html?id=…` 详情网页。正文、配图、头像和图标均为网页元素，不生成整张图片，也没有 PNG 下载或图片查看器入口。当前修改仅针对 `h5_share`，同级小程序项目未变更。

## 启动与使用

```powershell
cd D:\wechatShareProject\h5_share
npm start
```

电脑打开 [本地页面](http://localhost:5173/)。手机和电脑连接同一 Wi-Fi 后，可访问 `http://电脑的局域网IP:5173/`。本地服务不代表已部署到公网。

1. 设置头像、昵称、文案、配图、点赞人数和发送时间。
2. 点击“发表”，网址进入 `detail.html?id=…`，网页标题为“详情”。这是一次正常的 HTML 页面跳转，不打开 PNG、Blob 图片地址或图片预览弹窗。
3. 使用手机系统截图，可保留手机当前真实的时间、电话卡信号、Wi-Fi、电池及浏览器自身界面。在微信内，详情页直接使用微信原生标题栏，不再创建第二套 H5 导航或占位；使用微信返回操作回到配置。其他浏览器及主屏幕网页保留页面自己的返回和菜单。每次进入或刷新配置页，正文和配图均为空；从详情返回配置也会清空本次图文。最近头像和昵称继续从本机缓存恢复。详情页刷新后仍显示本次已发表内容。
4. 非微信环境的页面菜单只有返回配置和取消。微信原生关闭按钮、右上角菜单、布局和来源 IP/域名由微信控制，网页只设置标题为“详情”，不能通过 H5 CSS 修改它们。配图与头像不响应点击、长按的图片操作，方便直接截图。程序没有整图渲染和下载功能。
5. 时间、信号、Wi-Fi 和电池位于手机系统界面，电脑网页预览及网页区域截图不会包含它们。页面按本机安全区排版、不请求浏览器全屏；真实状态栏的显隐和样式由系统及打开网页的微信或浏览器控制。H5 无法强制恢复被宿主隐藏的状态栏，也无法移除微信或 Safari 自带的导航栏，因此原生朋友圈的整屏效果仍需真机核对，不能仅靠网页保证完全一致。

### iPhone 上减少浏览器界面，保留真实状态栏

用 Safari 打开同一个网页，选择“分享 → 添加到主屏幕”，若显示“作为网页 App 打开 / Open as Web App”则保持开启。随后从主屏幕图标进入，配置并发表，再使用手机系统截图。项目使用 `display: standalone`，同时明确设置 iOS 状态栏为 `default`，不使用隐藏状态栏的 `fullscreen` 显示模式；该方式保留网页自己的“详情”导航，避免普通浏览器地址栏和工具栏占位。

这仍是在线 H5，未提供离线功能，也无需小程序。iPhone 系统版本、安装方式与安全区行为需要真机验证；首次从主屏幕打开时，可能需要重新设置一次头像和昵称，因为微信、Safari 与主屏幕网页可能不共享同一份存储。说明依据：[Apple 添加主屏幕网页指南](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios)、[Apple 独立网页与状态栏说明](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)。

## 布局与功能

- 按用户提供的 iPhone 17 截图校对，以折算后的 942 宽为布局基准；正文约 40 字号、54 行高，随页面宽度适配。字体优先使用手机系统字体，其他设备的字形和换行仍可能存在差异。
- 主屏幕网页和普通浏览器的“详情”导航按原图重新校准：背景 `#efefef`、标题 `#000`，优先使用 iPhone 的苹方字体，402 宽下约 17px；导航内容约 44px 高，手机安全区另外计算。返回箭头与三点为 `#181818` 矢量图标，保持等比，三点的尺寸和右侧位置与参考图对齐。详情页底色与导航统一，正文保持白色。系统状态栏图标与字体仍由手机系统绘制，不以网页图形替代；其最终背景融合需在对应 iOS 版本上核对。
- 详情包含头像昵称、文案、等比配图、来源名称、发送时间、垃圾桶、两点按钮、爱心、点赞头像和底部评论栏。来源默认“51Talk无忧英语”，显示在配图下方、时间上方，使用参考图的浅灰色；可在配置页修改或清空，来源随本次详情保存。旧详情没有该字段时使用默认文案，显式清空则不显示。微信内直接使用微信原生导航，其他浏览器及主屏幕网页显示 H5“详情”导航。内容图标使用 SVG 矢量路径，避免 Unicode 符号随字体改变。参考图中的真实评论不会自动伪造。
- 点赞头像在结果页按八列方格排列。正文区域可滚动，顶部导航和底部评论栏保持固定；评论栏按参考宽度约 56px 的内容高度加本机底部安全区适配。页面使用实际视口和安全区，不强行拉伸整张图片。
- 手机操作系统负责显示时间、电话卡、Wi-Fi、电池和充电状态。H5 不绘制、不读取、不随机生成这些状态图标。旧 `device-status.js` 和状态栏参考图不属于当前页面运行依赖，也不放入静态发布包。
- 主头像和点赞用户头像均支持上传、单指移动、双指缩放、确认和取消；单张图片最大 20 MB。主头像缺失时显示浅灰十字背景，昵称缺失时留空。
- 配图最多九张，保持原始比例。长昵称换行后正常推动正文和配图，无配图时不额外预留图片间距；图标按原比例显示，整张网页不转换成图片。
- 点赞人数不含自己，范围 0～100。输入时不重建列表，离焦或按回车后生成目标人数；“添加用户”每次加一，删除和清空同步更新数字。发表前再次校验人数。
- 当前 100 张本地头像按男性 10%、女性 50%、风景 20%、卡通 20% 分配，整数人数使用最大余数法。完整图库中的自动头像不重复，手动上传头像和修改的昵称会保留。
- 自动昵称混合 200 个日常网名、英文单词、成语、诗意短句和网络用语，同批不重复。人物、风景和卡通为本项目生成的虚构素材，来源见 `assets/avatars/ATTRIBUTION.md`。

## 最近头像与昵称缓存

主头像和昵称保存在当前浏览器、当前网站来源的 `localStorage` 中。昵称输入或清空后保存；头像确认后缓存为 1024×1024 JPEG。再次进入优先恢复最近设置，主动留空的昵称也会保留，不被迟到的微信资料覆盖。通过旧 `?draft=…` 地址再次打开时会移除旧参数，正文和配图保持空白，不读取旧草稿。详情页保留发表当时的资料。

缓存没有应用主动设置的过期时间，但不能保证永久存在：清理微信或浏览器数据、隐私模式、存储空间不足及更换域名、协议或端口都可能使缓存不可用或不共享。缓存损坏、图片不可读取或存储被禁用时，页面仍可使用，头像回退为十字背景；手动上传和编辑仍然有效。

发表时的详情临时记录另存于本机 IndexedDB，sessionStorage 作为备用；与头像昵称长期缓存相互独立。临时详情保留 24 小时、最多 20 份，网址中的随机 ID 只用于当前网站和浏览器内读取本机数据，并不是可跨设备分享的内容链接。两个存储都不可用时，直接在当前文档展示 HTML 详情，不会退回图片生成流程。

## 部署到服务器

```powershell
npm run build
```

将 **`dist` 文件夹里面的内容** 上传到网站目录，保持相对路径不变。当前发布包为 110 个页面运行文件加一个构建标记，主要文件为：

```text
index.html / manifest.webmanifest / styles.css / app.js
profile-cache.js / moments-view.js
detail.html / detail-store.js / detail-page.js
assets/avatars/manifest.json 与 100 张 JPEG
```

无需上传同级小程序、测试、脚本、后端、环境变量或凭据。修改后重新运行构建，再上传最新 `dist`。`scripts/`、`tests/` 和说明文件只用于开发维护。前次清理已删除原始头像图集以及旧参考、预览截图约 18.7 MiB，运行素材完整保留；重建头像图集需另行提供外部源图，校验现有头像无需原图集。

本版静态资源版本为 `20261022-2`。本地服务器返回 `Cache-Control: no-store`，部署时也应避免长期缓存 HTML，更新全部发布文件后重新打开网址，避免微信继续运行旧版本脚本。

### 无损体积优化

100 张头像保留原始尺寸和解码像素，经过无损熵编码及渐进式扫描优化，不重设质量、不重新量化、不改变色度采样。发布清单另行精简为运行所需字段，完整来源记录保留在源码 assets/avatars/manifest.json。默认朋友圈图片已从 H5 项目和发布包移除，当前约 4.91 MB、110 个运行文件。

启动只后台读取头像清单，发表按钮不等待模板或 100 张头像全部解码；只有列表当前选中的头像开始下载。点击发表先恢复本地身份缓存并等待当前选中头像完整解码，远程微信授权请求不阻塞本地编辑和发表；加载失败时保留配置并提示重试，避免缺头像或人数不符。

维护时可使用已有的 Python、Pillow 和 `jpegtran` 运行 `python scripts/optimize-lossless.py --jpegtran JPEGTRAN_PATH` 先验证；添加 `--apply` 才写入更小且像素一致的结果。工具会在修改任何素材前验证全部候选图像；不依赖网络，也不会安装软件。这些工具仅用于维护，不是网页或静态部署的依赖。

## 可选微信资料授权

默认静态部署不需要公众号或授权后端。直接在微信里打开 H5 不能静默获得微信身份；没有缓存且未接入授权时，使用十字头像、空昵称，用户可自主设置。

以后接入具备网页授权条件的公众号时，再部署 `server.js` 与 `wechat-auth.js`，在服务器环境配置 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`、`WECHAT_OAUTH_REDIRECT_URI`，并配置对应 HTTPS 授权域名。AppSecret 不进入前端、`dist` 或 Git 仓库。资料通过同源受限接口提供；拒绝授权或读取失败不影响编辑，已缓存或手动设置的资料优先。授权逻辑有本地 stub 测试，尚未用真实公众号完成端到端验证。
